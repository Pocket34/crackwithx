## 🌟 Executive Summary

CrackwithX is **NOT** a generic AI chatbot, an AI notes generator, or a basic study planner.

College students receive fragmented notices across WhatsApp groups, college portals, emails, PDFs, and faculty messages, but struggle with the fundamental question: **"What does this mean for ME, what do I need to do, and what could go wrong?"**

CrackwithX is the intelligent layer between **INFORMATION** and **ACTION**:
$$\text{UNDERSTAND} \longrightarrow \text{DETECT} \longrightarrow \text{ACT} \longrightarrow \text{PREPARE} \longrightarrow \text{PROVE} \longrightarrow \text{IMPROVE}$$

## 🧠 CRACKWITHX X-ARENA (Multi-AI Workspace)

> *"Ask once. Get multiple AI perspectives. Get one better answer."*

Accessible directly via **`/x-arena`** and **`/app/x-arena`**, and prominently featured in the sidebar and dashboard:
- **Core Workflow:**
  $$\text{STUDENT PROMPT} \longrightarrow \text{MULTI-AI ANALYSIS (GPT, Gemini, Claude, Perplexity)} \longrightarrow \text{CROSS-CHECK & CONFLICT DETECTION} \longrightarrow \text{CRACKWITHX SYNTHESIS ENGINE} \longrightarrow \text{STUDENT-READY FINAL ANSWER}$$
- **Selectable Models:** GPT-4o, Gemini 1.5 Pro, Claude 3.5 Sonnet, Perplexity Sonar (clearly labeled with live status or transparent Demo Mode).
- **Special Student Modes:** 🎓 EXAM MODE, 💻 CODING MODE, 🎤 VIVA MODE, 📚 STUDY MODE, 🔎 RESEARCH MODE.
- **Smart Conflict Detection:** Highlights explicit disagreements between models (e.g. BCNF functional dependency preservation) with actionable advice for university marks.
- **Student-Ready Actions:** Copy Answer, Simplify (ELI5), Make Exam Ready, Make Short Notes, Generate MCQs, Start Viva Defense, and Save to Project DNA.

## 🔗 "One Connected System" Principle

CrackwithX is not seven siloed apps:
1. **Action Engine** detects: *"Your Capstone Viva is in 4 days."*
2. **Risk Radar** raises the project defense vulnerability flag and drops project health.
3. **Main Dashboard** surfaces an immediate Attention Center priority: *"AI Viva Practice Recommended"*.
4. Student enters **AI Examiner** to undergo high-pressure cross-questioning.
5. AI Examiner identifies weak areas: *"Database Failover & Concurrency"*.
6. Weak areas link into **Project DNA** and **Exam Forensics** for targeted revision.
7. **Opportunity Shield** flags an advance-fee scam $\rightarrow$ directly bridges into **Problem Solver** for reporting and official verification.

## 🛠️ Tech Stack & Directory Layout

- **Framework**: Next.js 14 (App Router)
- **Language**: TypeScript (Strict Mode)
- **Styling**: Tailwind CSS, Glassmorphic CSS variables, Ambient Radial lighting
- **Icons**: Lucide React
- **Celebration Effects**: Canvas Confetti
- **State Management**: Centralized `StudentProvider` connecting all 7 modules
